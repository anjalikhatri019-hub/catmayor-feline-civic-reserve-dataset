# CATMAYOR Real Civic Feline Demand v1.0

This repository hosts the participant-safe data release for **CATMAYOR — The Feline Civic Reserve**. Download `CATMAYOR_Participant_Data_v1.zip` from the [v1.0.0 release](https://github.com/anjalikhatri019-hub/catmayor-feline-civic-reserve-dataset/releases/tag/v1.0.0).

The ZIP contains `train.csv`, `test.csv`, `train_targets.csv`, `sample_submission.csv`, a dataset description, a README, and license notes. The data are derived from public-domain municipal animal-center and 311 records. Original transformations and benchmark additions are CC0 1.0 Universal. Raw source-event records, exact test dates, private labels, and organizer-only preparation/provenance are intentionally absent from the public archive.

The benchmark is retrospective. Reserve allocations are hypothetical and should not be interpreted as measured effects on animal welfare. See the included dataset description for field units, limitations, and generalization risks.
