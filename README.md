# CATMAYOR Real Civic Feline Demand v2.0

This repository hosts the participant-safe data release for **CATMAYOR — The Feline Civic Reserve**. Download `CATMAYOR_Participant_Data_v2.zip` from the [v2.0.0 release](https://github.com/anjalikhatri019-hub/catmayor-feline-civic-reserve-dataset/releases/tag/v2.0.0). Version 1.0.0 is superseded and has a different submission contract.

The ZIP contains `train.csv`, `test.csv`, `train_targets.csv`, `sample_submission.csv`, a dataset description, a README, and license notes. The submission predicts two weeks of intake and supplies a precommitted two-stage reserve policy, including one week-2 branch for every possible whole-block carryover. The data are derived from public-domain municipal animal-center and 311 records. Original transformations and benchmark additions are CC0 1.0 Universal. Raw source-event records, exact test dates, private labels, and organizer-only preparation/provenance are intentionally absent from the public archive.

The benchmark is retrospective. Reserve allocations are hypothetical and should not be interpreted as measured effects on animal welfare. See the included dataset description for field units, limitations, and generalization risks.
